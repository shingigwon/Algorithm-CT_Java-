# 투포인터 (Two Pointer)

두 개의 포인터를 이용해 조건을 만족하는 구간이나 쌍을 찾는 방식. O(N)  
슬라이딩 윈도우 - 두 포인터가 같은 방향으로 이동하며 구간을 유지한다.

## 적용 상황

| 상황 | 패턴 | 키워드 |
|------|------|--------|
| 정렬된 배열에서 합/차가 target인 쌍 | 양끝에서 좁히기 | 두 수의 합, target |
| 연속 구간의 합이 target 이상인 최소 길이 | 슬라이딩 윈도우 | 연속 부분합, 최소 길이 |
| 중복 없는 최장 연속 구간 | 슬라이딩 윈도우 | 최장 부분 문자열 |
| 정렬된 두 배열의 공통 원소 / 병합 | 각 배열 포인터 이동 | 공통 원소, 합치기 |

---

## 이분탐색 vs 투포인터 vs 슬라이딩 윈도우

| | 이분탐색 | 투포인터 | 슬라이딩 윈도우 |
|--|--|--|--|
| 정렬 | 필수 | 경우에 따라 | 불필요 |
| 탐색 방식 | mid로 절반 제거 | 양끝에서 좁히기 | 구간 유지하며 이동 |
| 시간복잡도 | O(log N) | O(N) | O(N) |
| 사용 상황 | 값 위치 탐색 | 합 / 쌍 탐색 | 구간 최적화 |

---

## 핵심

- 정렬 후 양끝 좁히기 : `left < right` 조건으로 교차 전까지 탐색
- 슬라이딩 윈도우 : 조건 만족하면 `left` 당기고, 아니면 `right` 확장
- 포인터 이동 조건을 명확히 정의해야 무한루프 방지

### 자주 하는 실수
- [ ] `left < right` vs `left <= right` 혼동
- [ ] 슬라이딩 윈도우에서 `left` 당기는 조건 누락 → 무한루프
- [ ] 정렬 안 하고 양끝 좁히기 적용 → 틀림
