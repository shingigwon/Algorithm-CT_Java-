# [백트래킹 (Backtracking)](https://en.wikipedia.org/wiki/Backtracking)

가능한 모든 경우를 탐색하되, 조건에 맞지 않으면 즉시 가지를 잘라내는 방식. DFS 기반으로 구현한다.

![백트래킹](https://velog.velcdn.com/images/kjyeon1101/post/a1018e4c-3896-41ba-89f5-ead121c732b6/image.png)

---

## 적용 상황

| 상황 | 키워드 |
|------|--------|
| 순열 | 순서 있음 / 모든 경우 |
| 조합 | 순서 없음 / 중복 없음 |
| 부분집합 | 포함 여부 선택 |
| N-Queen / 스도쿠 | 조건 만족 탐색 |

---

## 핵심

- 선택 → 탐색 → **복원** 3단계가 반드시 세트
- 가지치기 조건이 빠르면 빠를수록 성능 향상
- 중복 허용 여부에 따라 시작 인덱스 조절

### 자주 하는 실수
- [ ] 상태 복원 (`used[i] = false`, `list.remove()`) 빠뜨림
- [ ] 중복 허용/비허용 구분 실수 (시작 인덱스 `i` vs `i+1`)
- [ ] 가지치기 조건 너무 늦게 체크 → TLE
